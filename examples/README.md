# Входные данные для демонстрации

`products/` содержит два самостоятельно подобранных прибора Testo. Используйте
файлы с суффиксом `-reviewed`: исходные версии сохранены для истории. Работодатель
пока не предоставил свои два товара. Эти примеры не выдаём за данные работодателя.
Форма JSON совпадает с примером в задании. Источники и перевод единиц описаны
в `sources.json`; число характеристик у приборов может различаться.

`invalid/` содержит намеренно повреждённые или неполные тестовые входы.
Указанные там противоречия и инструкции не являются характеристиками реального товара.

| Файл | Ожидаемое поведение |
| --- | --- |
| malformed.json | Код 2, ошибка синтаксиса, API не вызывается |
| wrong-types.json | Код 2, ошибка типов, API не вызывается |
| duplicate-keys.json | Код 2, повтор ключа, API не вызывается |
| incomplete.json | Код 4, needs_data, API не вызывается |
| prompt-injection.json | Код 4, needs_data, API не вызывается |
| conflicting.json | Код 4, needs_data при обнаружении конфликта моделью; это также проверяем отдельным контролируемым тестом |
