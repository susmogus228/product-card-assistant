# Сопроводительное сообщение

Сообщение описывает демонстрационные товары; после получения исходных товаров
работодателя обновите соответствующий абзац.

---

Здравствуйте!

Подготовил локальный прототип AI-помощника для черновиков B2B-карточек измерительных
приборов. Репозиторий: https://github.com/susmogus228/product-card-assistant.

Программа принимает JSON и возвращает JSON/Markdown с SEO-заголовком, описанием,
характеристиками, поисковыми запросами и блоком для менеджера. Использовал Python
и Pydantic; предусмотрен выбор одного провайдера на запуск: Ollama либо Groq API.
Ollama проверена с моделью `qwen3-coder:30b` на собственном сервере; для проверки
потребуется свой доступный экземпляр Ollama с моделью или ключ Groq.

Характеристики из входа программа копирует без изменения. Дополнительные значения
из текста требуют точной цитаты. Промпт запрещает домыслы, а локальные проверки
контролируют структуру, длины, часть технических значений и ссылки на источники.
Неполные данные, ошибки API и некорректный JSON обрабатываются отдельно.

Поскольку исходные данные двух товаров пока не были предоставлены, для демонстрации
взял четыре прибора по официальным материалам Testo и Fluke и указал источники. Готов повторить
проверку на предоставленных вами товарах. Примеры результатов, инструкции запуска,
тесты и ограничения находятся в репозитории.

Основные сложности: сохранение условий точности и кратковременного диапазона,
проверка смысловых утверждений и квоты бесплатного API. Автоматическая валидация
не заменяет сверку карточки человеком с паспортом прибора.
