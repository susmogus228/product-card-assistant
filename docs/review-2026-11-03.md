# Повторная сверка демонстрационных карточек

Карточки и исходные JSON — демонстрационные материалы, а не данные работодателя.
Повторная проверка обнаружила неполноту исходных данных; исходные результаты
оставлены без изменений как исторические артефакты. Два исправленных входа и новые
результаты реальных вызовов сохранены с суффиксом `-reviewed`.

## Testo 905-T1

В [паспорте производителя](https://static.testo.com/image/upload/HQ/testo-905-fiche-technique.pdf)
строка точности указывает ±1 digit, которого нет в исходном JSON и в карточке. Время
отклика t99 в воде указано как приблизительно 10 секунд. В тексте результата есть
грамматическая ошибка «с встроенным». В JSON источник заголовка не ссылается на
характеристику диапазона, хотя заголовок содержит значение +350 °C.

## Testo 608-H1

[Инструкция производителя](https://static.testo.com/image/upload/Instruction-manual-and-Software/Instruction-manuals/testo-608-instruction-manual.pdf)
указывает погрешность влажности ±3 %RH при +25 °C и диапазон влажности без
конденсации. Эти условия отсутствуют во входе и результате. В [таблице производителя](https://static.testo.com/image/upload/HU/testo-608-adatlap.pdf)
строка точности также отмечена ±1 digit. Фразу о показе точки росы и минимальных/
максимальных значений нужно уточнить, чтобы она не обещала одновременный показ.

## Проверка двух дополнительных приборов

3 ноября 2026 года через действительный Groq API проверены два новых, отдельно
подготовленных входа по источникам [Testo 510](https://www.testo.com/en-KW/testo-510/p/0560-0510)
и [Fluke 62 MAX](https://assets.fluke.com/manuals/62max___umeng0100.pdf). Оба
возвратили статус `draft`. В первом исходное «не заявлена как входящая в комплект»
в SEO-тексте превратилось в категоричное «не входящая в комплект». Во втором
SEO-текст неоднозначно передал верхнюю границу диапазона погрешности около 0 °C;
в таблице характеристик исходные условия сохранились. Один первый запрос Testo
510 завершился ограничением квоты Groq; повторный запрос удался.

Это четыре демонстрационных прибора, а не оценка на большой выборке. Они не
доказывают отсутствие галлюцинаций: ссылки на источники и лексическая проверка
не гарантируют смысловую точность. Исправленные демонстрационные результаты сверены
вручную; каждый следующий черновик также требует сверки с первичными источниками.
